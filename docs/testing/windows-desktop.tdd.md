## Windows 安装与运行

- NSIS 安装程序构建成功，实际静默安装退出码为 0。
- 安装后的 EXE、桌面快捷方式、开始菜单快捷方式和 Windows 卸载项均存在。
- 对实际安装的 EXE 执行 Playwright Electron 检查：四板块、18 个视图，页面导航及子页记忆通过，沙箱与上下文隔离启用，页面不暴露 Node.js，未出现页面脚本异常。
- 使用隔离的临时配置与明确标注的模拟 2.0.0 发行数据，验证更新横幅、更新说明弹窗、自动检查开关与 Escape 关闭。模拟版本没有安装文件，不能触发安装。
- 实际安装程序使用 image_gen 生成的环绕轨道图标，PNG 与多尺寸 ICO 保留透明背景。

复现安装版检查：先安装软件，再把 `FUPANTAI_EXE` 设为安装后的 EXE 路径，运行 `npm run smoke`。测试使用独立的临时用户数据目录，结束后清理，不覆盖日常使用设置。

## 真实发布后的检查

发布正式 Release 并上传 EXE 和 `SHA256SUMS.txt` 后，执行 `node scripts/smoke-release.cjs`。它只在隔离测试配置中将当前版本设为 0.0.0，从公开 GitHub API 发现真实新版，通过软件内按钮下载公开安装包，等待 SHA-256 校验完成，并与本地发布清单核对。脚本不会启动安装程序。

该检查必须在 Release 公开后运行；单元测试中的模拟发行数据不能代替真实下载验证。
